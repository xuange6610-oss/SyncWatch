新手快速开始

从下载、双击启动、首次登录到邀请成员，只走一条最短路径。遇到错误时不要跳过数据备份和密码修改。

1. 下载正确版本

房主下载 Windows 服务器 EXE；成员下载客户端或直接用浏览器；Mac 按 x64/arm64 选择；Android 安装 APK。打开 最新 Release，不要下载源码快照冒充安装包。

2. 双击启动服务器

  1. 把服务器 EXE 放到有写入权限的普通文件夹。
  2. 双击启动，程序会自动初始化 Electron、Node 服务、端口、数据目录和内置 cloudflared。
  3. 如果默认端口被占用，使用软件显示的新地址；不要同时打开第二个服务器实例。
  4. 首次登录使用 admin / admin888，进入账户设置后立即修改密码。

3. 建房、上传和邀请

  1. 在房间管理中创建房间，设置密码和成员权限。
  2. 上传合法影片，等待分析完成；成员只有在批准后才能看到媒体。
  3. 先用同一 Wi-Fi 的浏览器验证播放、暂停、拖动和倍速同步。
  4. 再复制局域网地址或开启临时公网访问，把房间密码和链接发给可信成员。

4. 结束与备份

结束观影前停止公网 Tunnel；在服务器设置导出全部数据或复制完整的 SyncWatch同步观影-Data/。不要只备份 config.json，也不要把 secrets、日志中的令牌上传到 Issue。
