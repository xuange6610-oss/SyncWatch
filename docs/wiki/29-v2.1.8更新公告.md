# v2.1.8 更新公告

发布日期：2026-08-20

## 版本结论

`2.1.8` 已作为当前发布版本，分支为 `release/v2.1.8`，并同步到默认分支 `main`。GitHub Release 使用同一版本号和同一份更新说明，下载文件名全部带 `v2.1.8`。

## Android 修复与使用边界

Android APK 的版本号为 `2.1.8`、`versionCode=20108`，内置 Node.js Mobile `18.20.4` 和服务端依赖。通用包包含 `arm64-v8a`、`armeabi-v7a`、`x86_64` 三种 ABI。安装后可启动手机服务，使用 `127.0.0.1` 本机地址或手机在 Wi-Fi/热点中的局域网 IP 给其他设备连接。

Android 的“服务器处理请求失败”通常来自服务端资源不完整、运行时脚本未修补或客户端连到了错误的地址。本版构建脚本会在发布前验证 124 个生产 Node.js 包、36 个静态资源、ABI 和签名；服务端协议测试覆盖登录、注册、房间、Socket.IO、会话恢复、上传、播放、聊天和权限。

手机本机不能直接运行桌面版 `cloudflared.exe`，因此 Android 端公网按钮不会伪装成可用。要公网访问，请在 Windows/macOS/Linux/云服务器启动 SyncWatch 服务并开启 Cloudflare Tunnel，再让 Android 输入该 HTTPS 地址登录；Android 本机服务器仍支持局域网访问。

## 今日变更清单

1. 统一源码、公共配置、Docker、下载入口、协议默认版本、发现广播、导出/备份文件名和文档为 2.1.8。
2. 升级 Android `versionName=2.1.8`、`versionCode=20108`，并修复 Node.js Mobile 生成脚本的 Unicode 路由兼容性。
3. 修复部分 Node.js Mobile 18 环境缺少 `crypto.randomUUID` 时，游客账号创建、登录审计和设备会话抛异常的问题；新增 UUID v4 `randomBytes` 回退和管理员/游客登录回归测试。
4. 登录失败统一显示安全错误编号，服务端日志用同一编号保留堆栈，Android/Web 客户端不接收敏感堆栈。
5. 短屏横向聊天展开保持播放器与聊天双列；增强下拉框的原生指示器、禁用语义和自动化检查稳定性。
6. Windows/macOS Actions 改从 Cloudflare 官方 Release 获取架构匹配的 cloudflared；Windows runner 先生成/上传 Android APK，再组装离线完整包。
7. 生成并签名通用 Android APK，验证 v1/v2/v3 签名、三 ABI、124 个生产包和静态资源闭包。
8. 补充发布包、旧版本残留、Android、桌面和 28 文件 Release 资产清单校验，防止只改文件名、不改内容的假版本。
9. 更新 Windows/macOS/独立服务器发布说明、下载链接、Wiki 导航和 GitHub 用户名迁移后的所有入口。
10. 保留旧版本公告作为历史记录，不把历史内容伪装成最新版本。

## 从 v2.1.7 到 v2.1.8 保持不变

同步播放、房间、媒体上传/审核/队列、聊天/弹幕/语音、屏幕和网页共享、账户权限、邮件、备份、日志、管理中心 11 个模块、`SyncWatch同步观影-Data/` 数据结构、Apache-2.0 许可证和贡献流程继续沿用 v2.1.7；此次更新不删除这些功能，也不要求重建账号或房间。

## 28 文件发布标准

v2.1.7 的 GitHub Release API 有 26 个维护者上传资产，加上 GitHub 自动生成的 `Source code (zip)` 和 `Source code (tar.gz)`，页面共显示 28 个文件。后续正式版本必须保持这套规模：4 个 Windows、1 个 Android、12 个 macOS、4 个 Node.js、5 个 cloudflared；缺少真实构建产物时发布应停止，不得用占位文件或改名旧包凑数。

## 测试与限制

已通过仓库集成测试、账户后端回归、Android 源码包检查和 Gradle 构建。当前构建机没有 `adb` 真机/模拟器，无法替代用户设备完成触摸登录、厂商权限和后台保活实测；发布后请按 Android 教程完成一次真实设备回归。
