# 数据结构与备份迁移

第一次启动会创建 `SyncWatch同步观影-Data/`。它保存账号、房间、媒体索引、聊天记录、设置和安全材料，不是源码。

| 路径 | 内容 | 是否必须备份 |
| --- | --- | --- |
| `config.json` | 账号、房间、权限、媒体索引和服务器设置 | 是，不要手工编辑 |
| `chat-history.jsonl` | 聊天、私聊、公告、弹幕和语音记录 | 需要历史时备份 |
| `.secrets/` / `secrets/` | 邮件密钥、密码哈希和验证材料 | 是，绝不能公开 |
| `uploads/` | 原始影片、音频、字幕、图片和文档 | 是，与索引一起 |
| `compatible-media/` | FFmpeg 生成的兼容媒体 | 可重建 |
| `subtitles/` / `thumbnails/` | 转换字幕和缩略图 | 可重建但建议备份 |
| `avatars/` / `chat-images/` / `voice/` | 用户互动素材 | 按需求备份 |
| `logs/` / `crash-dumps/` | 诊断日志 | 提交前脱敏 |
| `tools/` | cloudflared 等工具 | 可重新下载 |

迁移步骤：停止服务 → 复制整个 Data 目录 → 在新机器放到程序旁 → 检查写入权限 → 启动并验证账号、房间、媒体、聊天和 Tunnel。不要在服务运行时复制或覆盖数据。
