# 发布文件与下载

| 文件 | 用途 | 边界 |
| --- | --- | --- |
| `SyncWatch-Experience-Client-Portable-v2.1.7-x64.exe` | 体验版；Windows 成员 | 只加入已有服务器，不启动服务端 |
| `SyncWatch-Standard-Server-Portable-v2.1.7-x64.exe` | 标准版；Windows 房主 | 绿色便携运行，内置 Electron/Node、媒体工具和 cloudflared |
| `SyncWatch-v2.1.7-Full-Offline-Installer-x64.exe` | 完整版；Windows 房主 | 可选安装目录、快捷方式、卸载入口和完整 Windows 服务端；内嵌 Windows、Android 与 macOS 离线下载文件 |
| Android APK | Android 成员或受支持的手机服务器 | arm64-v8a、armeabi-v7a、x86_64；需要系统权限 |
| macOS DMG/ZIP | Intel 或 Apple Silicon | 选择 x64/arm64，对应包由真实 macOS Actions 构建 |
| 独立服务器 ZIP | Node/Docker/长期部署 | 需要 Node.js 22+，包含生产依赖和启动脚本 |

体验版不包含服务器；标准版适合不安装直接运行；完整版是可安装的完整 Windows 服务器，并把真实 Android APK 和 macOS ZIP 作为离线下载资源装进 EXE。Windows 不会执行 APK 或 macOS 程序，房主启动服务后由对应设备下载并安装自己的平台文件。

下载后按 Release 页的 SHA-256 校验。Windows 使用 `Get-FileHash 文件名 -Algorithm SHA256`，macOS/Linux 使用 `shasum -a 256 文件名`。正式 Windows EXE 不需要用户安装 Node.js；Node 安装包只用于源码开发和独立服务端。
