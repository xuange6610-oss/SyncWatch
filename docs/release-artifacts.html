校验与安装

  1. 只从 GitHub Releases 下载与平台匹配的文件。
  2. Windows 用 Get-FileHash .\\SyncWatch同步观影-v2.1.6.exe -Algorithm SHA256；macOS/Linux 用 shasum -a 256 文件名。
  3. 服务器 EXE 双击后等待浏览器或 Electron 窗口打开；首次登录立即修改默认管理员密码。
  4. macOS 首次启动按系统提示允许网络、麦克风和屏幕录制权限。
  5. 独立服务器 ZIP 需要 Node.js 22+；正式 Windows EXE 不要求用户安装 Node.js。

Cloudflared 与 Node.js

cloudflared 是 Cloudflare Tunnel 连接器，用于把本机 HTTP、Socket.IO 和媒体 Range 请求转发为 HTTPS 公网地址。完整服务器包已优先使用内置文件，手工安装时只从 Cloudflare 官方 Release 下载并校验 SHA-256。Node.js 安装包只给源码开发和独立服务器使用；它不是 Windows EXE 的运行前置。

平台运行时不同：Windows EXE、Android APK、macOS DMG/ZIP 不能互相替代。Release 页面中没有对应成品时，请按构建文档自行生成，不要下载第三方同名文件。
