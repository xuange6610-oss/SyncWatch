从启动服务器到一起播放

不需要先理解全部技术名词。房主完成前三步，其他成员只需要一个地址。

  1. 1

    房主启动

    运行服务器 EXE，或在源码目录执行 npm start。

  2. 2

    完成安全设置

    登录默认管理员账号后立即改密码，再创建房间和房间密码。

  3. 3

    分享访问地址

    同一网络分享局域网地址；跨网络时启动临时公网访问或配置 HTTPS。

  4. 4

    成员加入

    成员用客户端或浏览器打开地址，进入房间后由房主统一开始播放。

一个房间里不只是一块播放器

房主控制共同状态，成员保留自己的设备音量和必要的本地选择。

同步播放
播放、暂停、进度、倍速和可选音量同步，客户端自动校正明显偏差。
媒体与字幕
本地上传、字幕、播放队列、缩略图和浏览器兼容格式转换。
实时沟通
公聊、私聊、弹幕、表情、图片、语音消息、全麦语音和全屏公告。
共享与协作
桌面或手机屏幕共享、网页共享，以及受支持桌面端的电脑音源共享。
账号与权限
好友、在线状态、权限组、注册审批、设备管理、封禁与操作记录。
服务器运维
数据导入导出、备份恢复、邮件验证、日志、网络诊断和可选 AI 中转。

数据目录到底保存什么

SyncWatch同步观影-Data/ 是这台服务器的运行数据，不是源码。迁移时应停止服务器并完整复制。

路径作用备份建议
config.json账号、房间、权限、设置和媒体索引必须备份，不要手工编辑
uploads/上传的影片、音频、字幕、图片和文档必须与索引一起备份
.secrets/、secrets/邮件密钥和管理员验证材料绝不能公开，随数据一起备份
compatible-media/自动生成的浏览器兼容媒体可以重建，空间不足时可在停机后清理
logs/、crash-dumps/运行和异常诊断信息提交 Issue 前先脱敏

只复制 config.json 会造成记录、文件或密钥不完整。软件内的“全部数据与配置”导出适合日常备份。

从源码启动，按以下四条命令

适合想查看代码或参与开发的用户。普通使用者应优先从 Releases 下载已经构建的文件。

PowerShell / Terminal
git clone https://github.com/xuange6610-oss/SyncWatch.git
cd SyncWatch
npm ci
npm start

第一次登录后马上做什么

  1. 打开 http://127.0.0.1:5000。
  2. 使用默认管理员账号 admin、密码 admin888 登录。
  3. 立即修改管理员密码，再创建房间。
  4. 先用局域网地址测试成员连接，确认成功后再配置公网访问。
